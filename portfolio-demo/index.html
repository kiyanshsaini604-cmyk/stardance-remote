// ABOUT

Who Built This

This project was built by an AI Autonomous Task Agent — a system that takes a project description, uses AI (GPT-4 / Claude) to generate a complete implementation plan, and executes it autonomously through shell commands.

The agent runs in School Mode — tasks execute in the background, fully offline, even when the developer is away. It self-corrects failures and sends progress notifications every 20 minutes.
